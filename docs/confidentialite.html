Le site

Le site ne dépose aucun cookie, n’utilise aucun outil de mesure d’audience et ne contient aucun formulaire.

  • Hébergement. Le site est servi par GitHub Pages. Comme tout hébergeur, GitHub reçoit l’adresse IP et les informations techniques du navigateur des visiteurs. Voir la déclaration de confidentialité de GitHub.
  • Dernière version. Pour proposer le bon fichier à télécharger, la page interroge l’API publique de GitHub depuis votre navigateur. GitHub reçoit alors votre adresse IP. Le numéro de version obtenu est gardé dans le stockage de session du navigateur pendant une heure au plus, puis effacé à la fermeture de l’onglet ; il ne contient aucune donnée personnelle.
  • Contact. Si vous écrivez à l’adresse ci-dessus, votre message et votre adresse e-mail servent uniquement à vous répondre. Ils sont conservés le temps de traiter votre demande et de son éventuel suivi, puis supprimés.

L’application

Finder fonctionne sur votre ordinateur. Il ne transmet ni vos fichiers, ni l’index de recherche, ni votre historique.

  • Données locales. L’index des applications et des fichiers reste en mémoire et disparaît à la fermeture. Les cinq dernières recherches sont gardées sur votre poste jusqu’à ce que vous les effaciez (Ctrl+Suppr dans Finder).
  • Recherche web. Le préfixe ??, ou le choix de « Rechercher sur Google » quand rien ne correspond, ouvre votre navigateur sur Google avec le texte saisi. Google reçoit alors ce texte, selon sa propre politique de confidentialité.
  • Mises à jour. Les versions .deb et AppImage vérifient les nouvelles versions auprès de GitHub au démarrage puis toutes les quatre heures, et la signature des mises à jour auprès de l’infrastructure publique Sigstore. Ces services reçoivent votre adresse IP et la version de Finder.
  • Aucune mesure. Aucune statistique d’usage ni aucun rapport de plantage n’est envoyé.
