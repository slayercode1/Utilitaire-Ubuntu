Questions fréquentes

L’essentiel, avant d’installer.

Sur quelles distributions Finder fonctionne-t-il ?

Le paquet .deb est prévu pour Ubuntu et Debian. Une AppImage x64 est également proposée pour les autres distributions Linux compatibles.

Finder est-il vraiment gratuit ?

Oui, Finder est gratuit pour un usage personnel et non commercial. Une offre payante pourra être introduite plus tard ; tout changement sera communiqué en amont.

Existe-t-il un équivalent de Spotlight sur Linux ?

Oui : Finder apporte à Linux une recherche universelle comparable à Spotlight sur macOS — applications, fichiers, calculs et conversions derrière un seul raccourci clavier, Alt+Espace.

Mes fichiers sont-ils envoyés vers un serveur ?

Non. L’indexation et la recherche de fichiers s’effectuent localement sur votre machine. Finder ne contacte l’extérieur que pour une recherche web que vous lancez, et pour vérifier ses mises à jour auprès de GitHub ; aucune mesure d’audience n’est collectée.

Comment installer la mise à jour suivante ?

Les versions Debian et AppImage vérifient les nouvelles releases et vous demandent avant de redémarrer pour appliquer une mise à jour.
